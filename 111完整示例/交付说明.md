# 蓟州区旅游经济建模交付说明

## 核心交付物

- `蓟州区旅游经济预测与政策优化论文.pdf`：匿名竞赛论文定稿，18 页。
- `蓟州区旅游经济预测与政策优化论文.docx`：可编辑 Word 版，18 页。
- `蓟州区旅游经济完整数据集_2010-2030.xlsx`：12 张工作表，含年度主数据、来源长表、质量标记、模型结果、预测、情景、敏感性和政策指标。
- `forecast_2026_2030.csv`、`scenario_forecasts.csv` 等 CSV：便于程序直接读取的结果表。
- `figures/`：论文使用的 10 张出版级图件。

## 数据处理原则

1. 每条观测保留来源、证据等级、数值状态和口径说明；同年同指标以高等级、可核验且口径明确的来源优先。
2. 2020—2022 年游客量缺失不作线性插值；2025 年尚无可核验完整年度实际值时保留为空。
3. 目标、累计值和搜索摘要旁证不冒充年度实际值；旅游综合收入与旅游直接收入严格区分。
4. 由于未获得口径一致的区县旅游收入价格指数，收入预测为名义值，论文已显式披露限制。

## 模型与随机性

- 简单模型：指数、Logistic、Gompertz、分段对数线性。
- 正式模型：分段趋势、阻尼 Holt、局部线性状态空间；采用滚动起点回测的逆 RMSE 加权组合。
- 统计预测区间：10,000 次模型选择与残差模拟；情景联合敏感性：20,000 次参数扰动。
- 所有随机过程固定种子 `20260817`。

## 复现命令

在项目根目录执行：

```powershell
python code/scripts/build_jizhou_analysis.py
python code/scripts/build_jizhou_figures.py
node scripts/build_jizhou_final_workbook.mjs
python scripts/build_jizhou_paper_docx.py
```

测试命令：

```powershell
python -m unittest tests.test_source_catalog tests.test_jizhou_data tests.test_jizhou_models tests.test_jizhou_scenarios tests.test_jizhou_figures
```

LaTeX 论文源文件位于 `tex/template/jizhou_tourism_final.tex`，参考文献位于 `tex/template/jizhou_tourism_refs.bib`。

## 使用提醒

2030 年游客量预测上界较宽，反映短样本、缺失年份与模型结构分歧；该区间是风险范围，不应直接转写为刚性政策目标。情景值是条件性假设结果，也不等同于统计置信区间。
