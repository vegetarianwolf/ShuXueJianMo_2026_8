# Bundled fonts

本目录中的字体随模板一起分发，供 Windows 和 macOS 使用同一套 XeLaTeX 输入。

| 用途 | 文件 |
| --- | --- |
| 中文正文 | `SourceHanSerifCN-Regular.otf`, `SourceHanSerifCN-Bold.otf` |
| 中文黑体 | `FandolHei-Regular.otf`, `FandolHei-Bold.otf` |
| 中文楷体 | `FandolKai-Regular.otf` |
| 中文仿宋 | `FandolFang-Regular.otf` |
| 英文衬线 | `texgyretermes-*.otf` |
| 英文无衬线 | `texgyreheros-*.otf` |
| 代码 | `YaHei.Consolas.1.11b.ttf`, `Fira Code Retina Nerd Font Complete.otf` |

Fandol 的完整许可证见 [`Fandol-COPYING`](Fandol-COPYING)。原模板自带的 Source Han 和代码字体文件保持不变。
